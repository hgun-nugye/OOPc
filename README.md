📘 **C# OOP Exercises – NTU**
Welcome to the C# Object-Oriented Programming (OOP) Exercises repository for NTU students.
This repository contains practice problems, sample solutions, and guidelines to help you strengthen your understanding of OOP concepts in C#.

**🎯 Objectives**
By working through these exercises, you will:
- Understand the fundamentals of OOP in C#.
- Apply concepts such as classes, objects, inheritance, polymorphism, encapsulation, and abstraction.
- Practice designing reusable and maintainable code.
- Gain hands-on experience with real-world problem-solving using C#.

**👨‍🏫 Instructor**
These exercises are taught by Master Nguyễn Đình Hưng at Nha Trang University (NTU).
His guidance emphasizes both theoretical foundations and practical applications, ensuring students are well-prepared for professional software development.

**🛠️ Requirements**
- IDE: Visual Studio / Rider / VS Code with C# extension
- .NET SDK: Version 6.0 or above
- Basic knowledge of programming in C#
